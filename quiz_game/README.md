# 🎮 Quiz Game in Python

A interactive, text-based quiz game built entirely in Python. Test your knowledge across multiple categories, track your score in real-time, and challenge yourself to get a perfect score!

## 🚀 Features

* **Multiple Choice Questions:** Engaged format with clear option selections.
* **Instant Feedback:** Dynamic evaluation of correct and incorrect answers.
* **Score Tracking:** Live percentage calculation and final score tally.
* **User-Friendly Interface:** Clean, easily readable terminal layout.

## 🛠️ Installation & Setup

Follow these steps to run the game locally on your computer.

### Prerequisites

Make sure you have Python installed. If not, download it from [python.org](https://python.org).

### Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the quiz game folder:**
   ```bash
   cd Python-Projects/quiz_game
   ```

3. **Run the game:**
   ```bash
   python quiz_game.py
   ```
*(Note: Replace `quiz_game.py` with your actual main Python filename if it is named differently).*

## 🕹️ How to Play

1. Start the game via your terminal.
2. Read the prompt question carefully.
3. Type the character or phrase corresponding to your answer.
4. Press `Enter` to submit and view the immediate result.
5. Review your final percentage score at the end of the round.
