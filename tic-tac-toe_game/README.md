### Python Tic-Tac-Toe

A lightweight, terminal-based **Tic-Tac-Toe** game written in clean, modern Python. This project allows two players to play the classic game directly from their command-line interface. 

### Features

- **Interactive Command-Line Interface:** Easy-to-read text-based rendering of the game board.
- **Robust Input Validation:** Prevents game crashes from invalid coordinates, letters, or already-taken spots.
- **Auto-Detect Win & Draw conditions:** Real-time checking for row, column, diagonal wins, or grid exhaustion.

### Tech Stack

- **Language:** Python 3

### How to Play

1. The game starts with a grid numbered **1 through 9**.
2. **Player X** always goes first.
3. When prompted, type a number matching an available spot on the board and press Enter.
4. Players alternate turns until someone aligns three identical markers horizontally, vertically, or diagonally—or until all spots are filled resulting in a draw.
